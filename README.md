# Forge trial client

This is KnackLabs' private trial client for Forge, which takes each change from an approved plan to a merged pull request.

## How it works

Run `forge next` whenever you are unsure. It says where things stand and gives the next step.

Work happens on a story, task or fix branch, never on `main`. The human approves stories and merges pull requests. See `AGENTS.md` for the rules.
